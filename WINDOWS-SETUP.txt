Satoshi's Council — Clean Windows install
=========================================

1) Extract the zip somewhere clean, e.g.:
   C:\Users\<you>\satoshi-council-full

2) Open PowerShell in that folder (the one that contains backend\ and requirements.txt)

3) Create venv + install:
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt

4) Run:
   $env:PYTHONPATH = "."
   python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload

5) Browser:
   http://127.0.0.1:8000
   Hard refresh: Ctrl+Shift+R

6) Settings tab:
   - BEAST mode, path targets, FADE, ANTI pairs, call bar,
     law lock, huddle time, sound, watermark — all editable
   - Click Save settings
   - Download brain.json anytime so learning survives machine moves

7) Optional — import an old brain after first start:
   Settings → Upload brain.json

If port 8000 is busy, stop the old server (Ctrl+C) first.
