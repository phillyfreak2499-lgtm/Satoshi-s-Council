# Long Desk decision framework v0

**Status:** FROZEN for Briefs #001–#004. Product-research rule, not a validated forecasting model and not public advice.  
**Purpose:** prove whether a repeatable Long Desk Brief is real without borrowing the Floor.

## Frozen v0 rule

1. Review once per week at **Monday 00:00 UTC**, using the completed Sunday UTC daily close.
2. Check 30-day structure: positive iff the 30-day return is **> 0%**.
3. Check 90-day structure: positive iff the 90-day return is **> 0%**.
4. Check drawdown healing: positive iff drawdown from the trailing-365-day closing high is less severe than it was 28 days earlier.
5. **STAND → HOLD:** 3/3 positive at two consecutive weekly reviews.
6. **HOLD stays HOLD:** at least 2/3 positive.
7. **HOLD → STAND:** 1/3 or 0/3 positive, or any decisive input is missing / stale / unreproducible.
8. **STAND stays STAND:** anything short of the two-review 3/3 confirmation. V0 has no ADD transition.

These thresholds and transition rules are frozen because Brief #001 already exists. The historical sanity check may describe behavior but may not retune them.

## Stance language

The Long Desk outputs are **ADD / HOLD / STAND**.

- **HOLD** = the slow evidence supports maintaining an existing Bitcoin ownership thesis; it is not an entry instruction for a non-owner.
- **STAND** = the slow evidence is mixed, deteriorating, incomplete, or constructive-but-not-confirmed; the Long Desk is not asserting a change in ownership behavior.
- **ADD** = a locked Long Desk noun, but v0 does not contain a rule that can produce it. Do not invent one during Briefs #001–#004.

WAIT remains Floor-only.

Every displayed stance must carry: **since DATE (N days)**.

## Allowed categories

A Brief may organize observations under:

- structure
- tape / participation
- derivatives
- context

Live seat votes never appear. Shared categories are allowed; shared conclusions are not.

The first line of every Brief must be an input the Floor does not vote on: weekly close, realized / holder cost basis, or time-underwater from ATH.

## Prohibited inputs

A Long Desk stance must not read:

- Chair UP / DOWN / WAIT
- live seat votes or seat confidence
- Kalshi strike or countdown
- current Kalshi order book
- one-window result or Floor P&L
- Floor win rate / "Council accuracy"
- current-window fair value
- a 15-minute derivative delta

A reader must not be able to derive the Brief from the week's Floor call.

## Daily status

The Brief is weekly.

A daily status chip may say only:

- **unchanged**
- **changed**

It does not create a new stance review or a new signal.

## What v0 does not claim

- It is not validated against future Bitcoin returns.
- It does not say HOLD will outperform STAND.
- It does not optimize thresholds on history.
- It does not use the Floor as a hidden feature.
- It does not recommend a position size.
- It does not create an ADD rule.
- It exists only to test whether four useful, clear, repeatable Briefs can be written.

No UI work begins during this proof.
