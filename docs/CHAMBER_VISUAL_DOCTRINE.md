# The Chamber — visual doctrine (amendment, 2026-09-13)

This document **amends, and does not rewrite,** `SATOSHI_DESK_FULL_PROMPT.md`. That
historical prompt governed the production Floor / desk UI, and its rules there are
unchanged: **the historical no-3D rule (no 3D table, no portraits, no looks-first
chrome) continues to apply to the production Floor and desk UI.**

## Scope

- `/chamber` is a **separately scoped observation interface, approved by the owner.**
- The Chamber has **zero research / decision authority.** It reads; it never decides,
  writes, votes, books, grades, settles, reconciles, promotes, alerts or posts.
- The Chamber **may** use 3D characters and a 3D environment.
- The Chamber **may not replace the Floor**, and **no production functionality may
  depend on WebGL.** If every Chamber file is deleted, the Floor is unchanged. A WebGL
  failure degrades only `/chamber`, to a plain fallback with normal navigation.

## The truth rule (unchanged, restated for the Chamber)

- **Ambient visual life may be fictional**: breathing, typing, glancing at screens,
  posture shifts, the Alchemist drifting between benches, terminal flicker, subtle
  equipment motion. These carry **no** semantic meaning.
- **Semantic claims and actions must be evidence-backed**: speech, Chair calls, seat
  claims, experiment outcomes, health incidents, research discoveries, system alerts.
  The Chamber never manufactures any of these. Phase 0 shows **labelled presentation
  fixtures**; any later live state arrives only through a read-only projection of the
  desk's public frame and is labelled as such.

## Paper-only

**Paper-only / no execution path remains absolute.** The Chamber adds no order,
trading, or execution capability of any kind, and never writes production state.

## Colour language

- **WORLD** (the 3D room): WAIT / inactive / observing = **dim neutral**; **amber** =
  research / attention; **green** = UP / healthy where contextually appropriate;
  **red** = DOWN / fault where contextually appropriate.
- **HUD**: the site's canonical product language, including the existing gold WAIT.

Both are intentional: the room's light is spatial system-state language; the HUD is
product UI.
