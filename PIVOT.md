# Pivot Notes — From Short-Horizon Kalshi Desk to Longer-Horizon Research Council

**Date:** August 2026

> **Current state (supersedes the notes below):** the desk has since consolidated to a **Bitcoin-only** research desk centred on SATOSHI with four ranked advisors, and re-added the Kalshi 15-minute market as a *lens* (not a trading engine). The "multi-coin" framing in this document is historical. See `README.md`, `DOCTRINE.md`, and `ROSTER.md` for the canonical current doctrine. This file is kept as a record of the reasoning behind the original pivot.

---

## Why the Pivot Happened

The original system was built as a sophisticated multi-agent desk for Kalshi 15-minute Bitcoin (and later ETH) markets, including path P&L / dual-sided logic.

That use case produced high stress and real-money losses for the operator.  
Short-horizon binary / path markets are noisy, high-turnover, and statistically difficult for retail participants after costs and behavior.

The visual system, agent framework, ranking, adaptive weights, and Round Table UI remain valuable.  
The *purpose* needed to change.

---

## What Changed

| Area | Old Focus | New Focus |
|------|-----------|-----------|
| Primary market | Kalshi 15m BTC (path / dual-sided) | Multi-coin longer-horizon research |
| Decision style | Frequent directional / path management | Fewer, higher-confluence decisions |
| Timeframe | Minutes | Hours to days / weeks |
| Output language | UP / DOWN / WAIT (+ path actions) | Accumulate / Buy Zone / Hold / Reduce / Sell / Wait |
| Capital stance | Paper with real-money temptation | Strict paper-first + process metrics |
| Success metric | Short-window hit rate / path P&L | Process quality + confluence + longer-horizon expectancy |

---

## What Was Preserved

- Canvas Round Table UI and cyberpunk visual language
- Agent seats, images, ranks, debate log, hierarchy
- Adaptive weighting and learning loops
- Chair synthesis model
- Dual-table architectural foundation (now extended toward multi-coin)
- Password / access gate patterns
- Overall modular agent contract

---

## What Was Retired or De-emphasized

- Pure Kalshi odds / strike / short-window path grading as the primary scoreboard
- High-frequency dual-sided scalp management as the main mode
- Any implication of live auto-trading or follower execution
- Marketing language that implied easy or frequent edge

---

## Current Stance

The Council is now a **research and process desk**.  

It forces ranked specialist debate and requires confluence before action.  
It treats a clean Wait as a successful outcome.  
It is intentionally slower and more selective than the original short-horizon version.

Paper tracking under the new rules is mandatory before any real capital is considered.

---

## Recovery Strategy

1. Keep and improve the existing visual + agent asset
2. Soft-monetize via simple membership
3. Sell the intellectual framework as *The Council Method* digital product
4. Use the same process discipline in parallel higher-probability second-income work (sales training products)

The goal is partial recovery of sunk cost + a living system that no longer creates stress and losses + a platform that can keep evolving.
